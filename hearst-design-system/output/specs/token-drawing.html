THE CONTRACT:
  1. Components read semantic or component tokens, never core values or hex.
  2. A brand may change color, type family, weight and radius; metrics, spacing and layout are system-owned.
  3. The nearest scope wins: :root → product → section → publication → portal root.
  4. Runtime guards keep labels and headlines readable whatever a brand sets.
