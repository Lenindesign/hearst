NOTES:(UNLESS OTHERWISE SPECIFIED)
  1. Do not scale from screen. Read the numbers.
  2. Measured with Playwright from the component library stories (all sizes, all variants, icon buttons, states, keyboard and touch), Chromium, fonts loaded, under three brand themes. Geometry is identical in all three; only R1 and colors change.
  3. Slots are placeholders. Label copy and icons are not part of the drawing.
  4. Variable column names the utility or token that sets the value; spacing utilities resolve as n × --spacing (0.25rem = 4).
 
  1. HUG = sized by content · FLEX = takes remaining space. Width is never fixed by the primitive.
  2. Variants (primary, outline, secondary, ghost, destructive, link) share every dimension on this sheet; they differ only in color tokens.
  3. Only touch (H5) and icon-touch (Z5) meet the 44 px touch minimum. Dense sizes are for pointer contexts or need an expanded hit area (T1).
  4. Grayscale by design. Gray fills separate states, not colors.
  5. Labels without descenders (g j p q y J Q) trim to cap height and baseline so they sit optically centered (Detail C); other labels keep line-box metrics.
