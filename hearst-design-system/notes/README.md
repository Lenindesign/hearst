# Working Notes

Use this folder for temporary research, meeting notes, and design exploration.

Working notes are not canonical product or design rules. Promote durable decisions into the owner listed in `VAULT_HOME.md`, and add decision history to `DECISION_LOG.md` when useful.

`archive/` preserves dated audits, plans, and QA evidence. Archived notes provide context only and must be revalidated before they influence current work.
