# Hearst+ Design System

Hearst+ is the cross-brand daily destination. The system should feel personal, useful, editorial, and habit-forming without inheriting every individual publisher theme.

The default mode should be dark. Hearst+ is a personalized daily destination, and the darker shell lets story imagery, brand logos, and editorial headlines carry the hierarchy. Light mode still belongs in the system as an optional high-brightness mode.

## Light Mode

Use light mode intentionally. It works best for high-brightness reading contexts or documentation, but the product shell should stay dark.

## Implementation Tokens

The app consumes these tokens through the Hearst+ theme variables, so the design system can evolve without replacing color values throughout the component tree.

```css
.hearst-plus-theme {
  --hp-font-ui: "Inter", system-ui, sans-serif;
  --hp-font-headline: var(--font-hearst-plus-headline, "Newsreader", Georgia, serif);
  --hp-background: var(--palette-background-page);
  --hp-surface: var(--component-card-background-default);
  --hp-control: var(--palette-background-subtle);
  --hp-primary: #384959;
  --hp-friendly-accent: #BDDDFC;
  --hp-friendly-accent-text: #384959;
  --hp-action: #384959;
  --hp-action-soft: #BDDDFC;
  --hp-action-soft-text: #384959;
  --hp-signal: #384959;
}

.hearst-plus-theme[data-mode="dark"] {
  --hp-background: var(--background);
  --hp-surface: var(--card);
  --hp-control: var(--muted);
  --hp-action: #BDDDFC;
  --hp-action-text: #384959;
  --hp-signal: #BDDDFC;
}
```
