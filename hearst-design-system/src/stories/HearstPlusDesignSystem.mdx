# AUTOS Design System

AUTOS is the focused daily destination for Hearst auto brands. The system should feel personal, useful, editorial, and habit-forming without inheriting every individual publisher theme.

The default mode should be light. AUTOS is a personalized daily destination, and the lighter shell keeps the car imagery, brand logos, and editorial headlines at the top of the hierarchy. Dark mode still belongs in the system as an optional immersive mode.

## Dark Mode

Use dark mode intentionally. It works best for immersive article reading or evening contexts, but the default product shell should stay light.

## Implementation Tokens

The app consumes these tokens through the AUTOS theme variables, so the design system can evolve without replacing color values throughout the component tree.

```css
.hearst-plus-theme {
  --hp-font-ui: "Inter", system-ui, sans-serif;
  --hp-font-headline: var(--font-hearst-plus-headline, "Newsreader", Georgia, serif);
  --hp-background: var(--palette-background-page);
  --hp-surface: var(--component-card-background-default);
  --hp-control: var(--palette-background-subtle);
  --hp-primary: #384959;
  --hp-friendly-accent: #BDDDFC;
  --hp-friendly-accent-text: #384959;
  --hp-action: #384959;
  --hp-action-soft: #BDDDFC;
  --hp-action-soft-text: #384959;
  --hp-signal: #384959;
}

.hearst-plus-theme[data-mode="dark"] {
  --hp-background: var(--background);
  --hp-surface: var(--card);
  --hp-control: var(--muted);
  --hp-action: #BDDDFC;
  --hp-action-text: #384959;
  --hp-signal: #BDDDFC;
}
```
