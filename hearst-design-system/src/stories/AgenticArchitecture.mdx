## Runtime composition

```text
Next.js route
  -> ThemeProvider
  -> ReaderAccountProvider
  -> HomePageTemplate
     -> destination navigation and masthead
     -> current story inventory
     -> personalized ranking and reader state
     -> story river, rails, video modules, and overlays
     -> in-app standard reader and Ambient Reader
```

## Source-of-truth order

1. `DESIGN-SYSTEM-SPEC.md` owns HDS token and component contracts.
2. `PRODUCT.md` owns product intent.
3. `STYLE.md` owns shared visual and interaction behavior.
4. `BRAND_STYLES.md` owns destination and publication identity.
5. `APP_RULES.md` owns feed, personalization, video, and reader behavior.
6. TypeScript source owns the current executable implementation.

## Data flow

The checked-in river data files make the Storybook and production build deterministic. `npm run feed:refresh` updates those inputs from public Hearst RSS metadata, enriches writer bylines, and validates the result. Deployment is a separate, explicitly authorized operation. Storybook does not call the production content API by itself.

## Personalization boundary

The current ranking model combines story metadata with browser-local signals such as followed topics, followed brands, saves, hides, time of day, and return-visit state. The stakeholder console explains those inputs. It is an executive prototype of product behavior, not evidence of a deployed machine-learning service.

## Provider contract

Stories that render `HomePageTemplate` must include both `ThemeProvider` and `ReaderAccountProvider`. Storybook supplies the reader provider globally and the integrated Hearst+ story supplies its explicit theme. A missing provider is a Storybook configuration defect, not an application empty state.

## Verification contract

- Run TypeScript and Next.js builds for source integration.
- Run the Storybook production build for catalog integrity.
- Inspect interactive stories at 320px, 390px, tablet, and desktop widths.
- Exercise keyboard focus, modal close and focus restoration, light/dark mode, and one publication theme.
